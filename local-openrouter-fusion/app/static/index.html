How it routes

Coding tools talk to POST /v1/chat/completions with model local-fusion (or one of the mode variants). The proxy fans the prompt out to the configured analysis models in parallel, optionally runs a critique pass, then synthesizes one final answer via the judge model and returns it in OpenAI format. The client sees a single completion — fusion is invisible to it.
OpenAI base URL: http://localhost:8000/v1
Model: local-fusion · local-fusion-code · …
Auth: Authorization: Bearer <service key>
Streaming: supported (single fused chunk)
